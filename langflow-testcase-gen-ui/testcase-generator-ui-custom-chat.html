💡 Pro Tips

  • Be Specific: Add constraints like budgets or user roles
  • Edge Cases: Mention boundary conditions (zero amounts, max transfers)
  • API & UI Tests: Specify backend, frontend, or integration tests
  • Test Scenarios: Ask for happy path, sad path, and error scenarios
  • Reuse Outputs: Copy and refine iteratively
